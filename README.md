# 3D Assets

This repository stores public 3D asset files used by earlier visual/web experiments.

It is an **asset repository**, not a representative engineering portfolio. The `.glb` files are kept here so they can be referenced independently from application code without mixing large binary assets into the main technical repositories.

- [BIMMCA Intelligence](https://github.com/naraya07pedro-spec/bimmca-intelligence) — Supabase-backed dashboard/application surface fed by an n8n monitoring architecture
